---
name: Code style - minimal comments
description: User wants very limited comments in code, only where absolutely necessary
type: feedback
---

Use very limited comments in all code. Only comment where logic is genuinely non-obvious. No docstrings on obvious functions, no section headers, no explanatory prose.

**Why:** User preference for clean, readable code without comment clutter.
**How to apply:** Write self-documenting code. Skip comments unless something would be confusing without them.
